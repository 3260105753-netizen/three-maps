
## 三、每张图在看什么

| 图 | 看什么 | 结论指向 |
| --- | --- | --- |
| `00_raw_rgb` | 杯子清清楚楚，看不出任何异常 | RGB 是"骗人"的，这就是为什么必须画中间结果 |
| `01` | 检测框和掩码都正常，说明**识别没坏** | 失败不在"检测不到" |
| `02` | 杯面 **27.7%** 的像素红色（无深度），集中在掠射角大的边缘 | 感知层：深度缺失，与 ClearGrasp 一致 |
| `03` | 同一物理点，两套标定差 **16.2mm**（22.5px） | 标定层：误差被放大成毫米级偏移 |

**归因结论**：失败落在**感知层（材质→深度缺失）**与**标定层（外参误差）**，不在策略/模型容量。

## 四、诚实边界（必须写进页面）

- 合成场景：无真实传感器噪声、无接触物理，**只能证明量级**；
- 真实相机的失效分布不同，27.7% 只作参考；
- **2°/15mm 是假设值**，真机标定后要替换；
- 分割与位姿用的是几何真值，目的就是**把标定误差这一项单独隔离出来**，不代表真实系统里检测也这么准。
