## 第 1 分钟：选题、范围、想帮同学理解什么

**点**：首页 → 往下滚到「这个网站讲什么、不讲什么」

**说**（三句，别多）：

1. 「我们研究**具身智能**，范围卡死在**一句话指令下的取物与递送**——机器人听懂一句话，找到桌上的东西，抓起来递到人手上。」
2. 「我们不展开硬件机构、电机驱动、多机器人协同、自动驾驶。」
3. 「希望同学看完能回答三个问题：这条任务链上每一环靠什么、这些工具和机构怎么连、以后该去哪学。」

**如果被问"为什么这么窄"**：窄才好讲。全组一半以上的节点都是围绕这一条任务链建的，换一个任务这些关系就不成立了。

## 第 2–4 分钟：带同学探索三张地图（核心 3 分钟）

### 2.1 领域地图（约 70 秒）

**点**：`领域地图` → 关系图里点**「一句话取物与递送」**（最中间那个大方块）

右侧卡片出现，从上往下指：

- **典型任务 / 已初步理解**：「这是我们选的典型任务，理解程度是我们自己评的——能讲清各环节，但没亲手跑过仿真。」
- **关系区**：找到 **「跨物体泛化失败 → 让泛化问题显现」** 这条，读它的 `why`：
  > 「任务要求对没见过的日常物体也能成功，这直接暴露策略跨物体泛化不足，演示视频的成功率掩盖不了它。」
- **点这条关系里的来源**：`Vision-Language-Action (VLA) Models…`（arXiv 2505.04769，已核实）
  > 「这条判断不是我们拍的，是这篇综述里的。」

**一句话收**：「一个节点 = 一句话说明 + 为什么这么连 + 凭什么 + 我们自己理解到哪。」

### 2.2 生态地图（约 60 秒）

**点**：`生态地图` → 关系图里点 **「Figure AI」**

- 指 **生态角色** 三栏：主要贡献 / 入选理由 / 相关成果
  > 「我们刻意不写排名，只写它做了什么、凭什么进来、有什么成果。」
- 指关系里的 **「Tesla Optimus ←→ 竞争」**，注意它带着橙色 **推断** 标签：
  > 「这条是我们推的，没有公开证据，所以标了『推断』、核实状态是『待核实』。课程要求区分事实和推断，这个标签就是干这个的。」

### 2.3 认知地图（约 50 秒）

**点**：`认知地图` → 点 **「吃对药而非抓住药」**

指五段式：
> 「案例不是讲故事，是这个固定格式：具体问题 → 使用方法 → 依据与比较 → 当前判断 → **尚存疑问**。最后一栏必须写我们还没解决什么——这条写的是『没有任何真实用户访谈』。」

### 2.4 三张图怎么连起来（约 20 秒）

**点**：这张卡「关系」里的 **「一句话取物与递送」** → 跳回领域地图并高亮

> 「三张图共用一套节点和关系，所以能从认知案例直接跳到领域任务，不是三个孤立的网站。全站现在有 7 条这样的跨图连线。」

## 第 5–6 分钟：AI 能力（2 分钟，三问）

### 演示 1：概念查课程（40 秒）

**点**：`AI 能力` → ① 概念查课程 → 输入 **模仿学习** → 查询

- 命中「模仿学习（示教学习）」，带 **4 个引用节点、6 条来源**
- 相关课程：**机器学习** —— 这里主动说明：
  > 「这门课的名字现在还写着『按本校课表改名』，依据也还没补原文，所以它标的是『待核实』。这是我们已知要补的一项，不是我们忘了。」
- 相关工具：**LeRobot 开源工具链**

### 演示 2：关系解释（50 秒）

**点**：② 关系解释 → 起点选 **换个杯子就失败**，终点选 **一句话取物与递送** → 解释关系

输出 **2 跳**：`换个杯子就失败 → 跨物体泛化失败 → 一句话取物与递送`

> 「它没有直接连，中间经过『跨物体泛化失败』。每一跳都说清为什么成立、证据是事实还是团队推断。下面这块是引用：哪些节点、哪些来源、团队理解程度。」

### 演示 3：它答不上来（30 秒）★ 最关键

**点**：① 概念查课程 → 输入 **自动驾驶** → 查询

输出：**「地图里没有找到「自动驾驶」」** + 列出地图现有标签 + 提示先补节点

> 「这就是我们不做通用聊天机器人的原因。它不会替我编一个解释。课程要求『没有依据时应说明不确定』，这一屏就是那个要求的实现。」

> 备选词：量子计算、SLAM、强化学习（强化学习确实也不在图里，可以顺带说"这也是我们要补的缺口"）

### 备用：路线比较（时间够再演示）

**点**：③ 路线比较 → 路线 A「端到端 VLA」vs 路线 B「模仿学习（专用小模型）」

结果：共有依赖 2 个（Open X-Embodiment 数据集、一句话取物与递送）、各自独有 2 个、2 个节点仍是「待深入学习」。生态侧对照：共用 OXE 数据集；只有 VLA 用到 DeepMind、Figure、Physical Intelligence；只有模仿学习用到斯坦福、LeRobot、DROID

> 「共有依赖说明两条路线其实都踩在同一批数据上（都依赖 OXE）；生态侧更能看出分歧——VLA 侧是企业主导，模仿学习侧是高校加开源社区。」

## 第 7 分钟：一次重要更新

**点**：`更新记录` → 找 **2026-10-22「生态地图：整图替换（24 节点 / 24 关系 / 25 来源）」**

读它的五栏：日期 / 改了什么 / 为什么改 / 依据 / 记录人。

然后往下找 **2026-10-21「来源 s.plan-gap（培养方案）」**：

> 「这条是『修正』类。我们原来把培养方案标成『已核实』，后来发现那个链接是学校教务系统，别人点开只会看到登录页——一个别人打不开的链接等于没有来源，所以我们自己把它降成了『待核实』。」

> **这一条比任何"我们做得很好"都管用**：它证明我们知道什么叫可追溯。

如果已经有同学反馈：改读 `changelog.html#feedback` 里的一条，按"提出什么 → 怎样核实 → 改了什么 → 为什么这样处理"念。

## 第 8 分钟：一次认识变化 + 仍不知道什么

**点**：`认知地图` → 滑到底部 **「还没解决的问题 & 下一步学什么」**

1. 先看左栏「仍然不知道（4 条）」：三条案例的尚存疑问 + 一条认识修正的未知
   > 「这 4 条不是我们编的，是从每个案例的『尚存疑问』自动汇总的，改案例它就变。」
2. 再点上面的 **「瓶颈搬家」**（认识修正）：
   > 「我们原来以为瓶颈在模型结构；读到 Figure 关于 Helix 的说明和 VLA 综述关于评测口径的讨论后，改判为当前瓶颈更多在数据质量与评测口径。这是本组真实发生的排序变化。」
3. 收尾：
   > 「下一步两步：一是补真实用户访谈，二是领域地图还缺一个 sim2real 节点——认知案例里最关键的推理现在在领域侧没有落点。」
